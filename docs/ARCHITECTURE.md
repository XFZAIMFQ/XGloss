# 工程结构

```text
src/
  domain/             词汇、分词、统计与运行时数据契约
  data/               扩展源 IndexedDB 和受限配置存储
  services/           查词、兼容翻译与后台业务处理
  platform/           类型化扩展消息
  features/
    web/              网页分片扫描与视口高亮
    pdf/              PDF.js 页级生命周期
  components/         共用词卡与阅读面板
  assets/             共用界面样式
  entrypoints/        后台、内容脚本、弹窗、设置、词库、PDF 阅读器
scripts/              资源准备工具
tests/                数据一致性与服务协议回归验证
public/               随扩展打包的词典资源与许可
```

## 数据流

内容脚本和阅读器从原始文本提取 token，再按同一套词汇状态计算词频及覆盖率。遇词位置保留源信息，词汇状态按归一化后的英语词条共享。

所有持久化写入经过后台业务处理器，IndexedDB 事务同时更新词条与遇词记录。界面收到成功回复后更新状态。后台通知其他标签页重新读取词汇，PDF 页和网页共享更新。

后台仅向内容脚本返回词汇状态和查词结果。设置读写只允许扩展页面调用。chrome.storage.local 访问级别设置为 TRUSTED_CONTEXTS，持久化 API Key 位于受限配置中。

## 翻译协议

Base URL 表示 API 根路径，例如 https://example.com/v1。使用 POST {baseUrl}/chat/completions，提交 model、messages 和 stream=false。Authorization 使用 Bearer，密钥可留空以兼容本机服务。基础请求保持最小字段集。

翻译任务包含选中文字、目标语言和可选原句。上下文提示明确选词位置与任务要求。模型输出按纯文本展示，缓存按配置指纹和输入计算，设置变化后缓存隔离。响应需包含 choices[0].message.content 字符串，服务端错误转换为明确反馈。

一次调用有超时，后台限制并发翻译请求，缓存写入失败仍可返回翻译结果。用户可编辑已有配置并测试连接。远端 HTTPS 与本机 HTTP 服务均通过用户操作申请来源权限。

## 网页与 PDF 生命周期

网页初始发现与增量扫描均按时间和节点数分片。每个文本块保留词频摘要，活动高亮仅覆盖视口及附近区域，并有范围数量上限。MutationObserver 将变化加入队列，移除节点释放引用。

PDF.js Worker 解析文档。首个版本使用分页阅读，Canvas、文字层和高亮仅保留当前页，后台统计可逐页推进。变更缩放或文件时取消旧渲染，旧 generation 结果丢弃。大文件仍受单页复杂度、解码和文件本身大小影响。

## 实施范围

当前阶段实现网页、带文字层 PDF、本地词库和可配置在线翻译。扫描 PDF 的 OCR、欧路同步及更多语言保留后续接口演进空间。
